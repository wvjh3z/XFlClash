# 任务材料与正式归档

本页唯一维护临时目录、测试材料和交接归档规则；验收条件见[ACCEPTANCE](ACCEPTANCE.md)。不改现有构建输出路径，不将原始日志、安装包或密钥批量加入Git。

## 存放位置与用途

下表是从本约定起使用的规则。含`<任务ID>`的是路径模板，须替换为日期加唯一任务名；不是已存在目录或可直接执行的命令。

| 材料 | 负责位置 | 交接要求 |
| --- | --- | --- |
| 中间脚本、抓取、比对、临时测试输出 | 本机 `/root/dev/maintenance/xflclash/tasks/<任务ID>/`，按需创建；同一任务集中，不散在仓库根或公共/tmp | 临时工作区，不是正式证据唯一来源；结束时分类提升或清理 |
| 已有正式工具产生的报告 | 保留其既有批次目录，如`.local-build/...`、Android批次diagnostics、GitHub artifact | 不手改工具路径；收尾按下列证据规则转存必要文件并登记来源 |
| 可复用客户端测试/夹具 | 客户端`test/`、`tool/test/`及已有就近夹具目录 | 可随源码取得，正负控与实际入口绑定；不依赖某次临时脚本 |
| SDK/插件/文档工具测试 | 各负责仓的现有测试目录，Docs为`tools/` | 不跨仓复制同一套实现；不得把SDK测试藏在客户端临时目录 |
| 必要的脱敏验收摘要/小型机器报告 | 当前Docs `evidence/<任务ID>/`，按需建立并纳入Git；已有STATUS或失败记录足够时直接引用，不另建重复报告 | 标明源码、环境、命令、退出码、范围与限制；不能仅提交“通过”截图 |
| 大型成品、匹配符号、必要原始采集与恢复材料 | 本机 `/root/dev/maintenance/xflclash/archive/<任务ID>/`作为集中归档；含敏感数据限制目录/文件访问；另按授权保存在可持续取得的受限存储 | 项目资料保留不含秘密的索引、大小/摘要、身份匹配、访问/恢复方式及实际可用性；本机单份不等于异机交接完成 |
| 密钥、签名、Token和生产凭据 | 保持ACCESS/专项手册登记的既有受限维护源 | 不迁入公开目录、Git或普通证据包；索引只写取得条件和用途，不回显值 |
| 历史决定与版本失败经验 | Docs/history、客户端docs/build-failures，按既有职责维护 | 标明版本/日期/替代关系，不作为当前执行步骤 |

本机路径规则不要求其他维护者拥有`/root/dev`。换机先在该工作区选定等价的任务临时根和受限归档根，并在任务证据索引登记实际位置与访问条件；不能把本机绝对路径当作异机已交付的证明。`Docs/evidence/`内的Markdown索引（含子目录）纳入文档链接检查；二进制内容、权限、摘要和远端保留期仍需实际验收，链接检查不能替代。

“生产原始采集”包括用户错误日志、Sentry事件、主机诊断与配置快照，可能含隐私或凭据。保持原件和脱敏副本的区别，只在授权范围取得与留存；不要为了满足归档而主动扩大采集。共享符号、原签名和已登记恢复材料不能按临时垃圾清理。

## 从临时材料提升为正式证据

1. 分清一次性输出、可复用测试、验收必需证据和恢复材料；由负责仓维护可复用代码，证据留在实际任务对应的归档。
2. 为必要文件登记来源、采集时间、对应提交/包/运行、大小/摘要和完整/部分/缺失状态；多个报告不能拼成未经说明的同一次成功。恢复材料额外记录适用版本、恢复步骤入口与最近验证范围。
3. 敏感原件限制访问，另生成脱敏摘要；检查解压/展示是否会暴露秘密。对需依赖远端artifact的证据记录保留期限；过期前按授权转存，或明确交接缺口，不承诺其永久可用。
4. 核对索引能在另一检出中找到，接手者有实际访问或明确申请路径。只剩被忽略的`.local-build`、临时目录、聊天附件或已过期artifact时，正式交接不通过。用户暂不允许提交时保留本地资料，明确“尚未正式交付”，不能擅自推送。

归档摘要用于核对维护材料身份，不改变客户端更新下载不做SHA256校验的产品决定。不要把大型文件入Git当成唯一交付方式；受限存储尚未配置或未获授权时，写清缺项及对交接的影响。

## 清理与并行任务保护

清理前查看本任务清单、Git差异及运行任务/进程对路径的使用情况，核对目录归属；不能由“很旧”“被忽略”“在/tmp”推断可删。先确认复制/归档完整和索引可访问，再清理本任务可再生成的材料；无法确认归属或仍被其他任务使用的内容保留并记录。禁止整仓`git clean`、批量删除maintenance、清理其他项目缓存或删除worktree公共Git目录。

此次约定不追溯搬动所有历史证据；旧的有效材料按现有索引保留，后续处理到对应任务时迁入集中归档并同步引用。旧操作文档已退役，不等于其引用的真实成品、符号、签名或恢复材料可以删除。既有测试必需使用系统临时目录时保持隔离夹具机制；需要交接的失败证据在清理前提升归档。
